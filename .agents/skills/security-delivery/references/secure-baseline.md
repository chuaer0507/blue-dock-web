## 1. 密钥与配置安全

### 1.1 基本原则

- API 地址、WS 等经各 app `.env.development` / `.env.production` 注入（Vite `VITE_*`）
- 代码统一经集中 env 模块读取，禁止业务散写 `import.meta.env` 拼密钥
- **禁止**把密钥硬编码在源码、测试、注释、示例、i18n、日志配置默认值中
- 生产 env 与 CI Secrets 可见性受控；禁止推到公开仓库
- 示例 / 模板 env 只允许非敏感占位
- `.env.local` 与含密钥的本地覆盖必须 gitignore

### 1.2 分层读取

- 编译期 / Vite 环境 → 集中 env 模块
- 运行时偏好 → storage + 明确 key（按用户隔离）
- 第三方 SDK（Agora 会议等）初始化集中入口，文档标明环境来源
- 页面 / hook **不**直接解析原始 env 字符串拼密钥

### 1.3 脱敏与展示

禁止完整输出：

- Access Token / 微应用注入 token
- 密码、验证码、会议 `shareKey` 全文
- 身份证号等个人敏感信息
- 完整签名串 / 抓包原文

必须展示时只允许脱敏。故障排查看原文走受控手段，禁止临时 `console.log` 打全文。

### 1.4 存储与清理

- Token、用户资料走既有 auth / storage；遵守 persist 白名单
- 登出清理会话项；勿存密码明文
- `localStorage` 同源可读，最小化
- 会议分享态、上传临时凭证随场景清理

### 1.5 轮换与失效

- 依赖后端 token 失效策略；前端 logout 至少清本地 token
- RSA 公钥 `keyId` 轮换由密码加密链路支持；过期公钥须可理解处理

## 2. 输入输出与边界安全

### 2.1 输入校验

所有外部输入不可信：

- 表单、路由参数、WebSocket 载荷、文件选择、粘贴板、微应用 postMessage

规则：

- 表单先做格式、长度、必填，再调 API（Zod + RHF 推荐）
- 权限相关不变量调用前再确认
- 禁止把原始输入拼进文件路径、脚本、未校验 URL
- 排序 / 筛选字段走白名单或既有枚举
- 不确定字段用 `unknown` + Zod，禁止默默 `any`

### 2.2 文件与上传

- 类型 / 大小按系统设置与契约校验
- 分片协议可取消；失败可理解提示
- 预览外链校验协议与业务域名

### 2.3 URL / 外链

- 打开外部 URL 前校验协议（优先 https）与业务白名单
- Electron 外链经 `shell.openExternal`，不在内嵌随意导航

### 2.4 WebSocket

- 单例按 URL 复用；切换用户 / URL 销毁旧实例
- 事件类型化；未知 type 安全忽略
- 重连有退避；UI 可展示连接状态，不把内部异常栈抛给用户

### 2.5 微应用消息

- postMessage 校验 `origin` / 约定 source
- 桥 API 最小权限；选人、代理请求等敏感能力需明确鉴权与审计意识

## 3. 敏感数据治理

### 3.1 分类

至少识别：

- 账号身份与 Token
- 联系方式、组织架构
- 会议分享、文件分享链接
- 聊天内容、任务内容、审批内容
- 签到人脸 / WiFi 相关公开接口边界（`api/public/attendance/*`）

每类明确：可见范围、是否落本地、日志策略、是否可注入微应用。

### 3.2 传输与模型

- 密码仅密文上送；响应模型无 wire `password`
- 缓存敏感快照必须有生命周期
- mock / 真机均不得 echo 密码

### 3.3 日志与错误上报

- logger / 拦截器默认避免完整敏感 body
- 错误上报（若接入）：DSN 未配置则跳过；事件中勿附带 token / 密码
- 用户可见错误用业务文案，勿暴露底层内部信息

## 4. 供应链与发布安全

### 4.1 依赖治理

- 新依赖说明用途、维护状态、许可证与替代成本
- 禁止长期保留无维护或来路不明包
- Electron / 会议相关依赖评估权限清单与降级

### 4.2 构建与制品

- 经 `bun run build` / CI 构建，可复现
- 禁止个人机器手工改产物后当正式包
- Secrets 未配置应跳过而非失败泄露

### 4.3 上线前安全检查

- [ ] 无硬编码密钥、Token、密码、DSN 真值
- [ ] 无未脱敏敏感日志
- [ ] 密码明文上送与响应 password 字段均为否（生产路径）
- [ ] 敏感动作不仅前端隐藏，失败路径可理解
- [ ] 无测试后门、强制跳过鉴权的调试开关留在 release
- [ ] 无误提交 `.env.production` 真密钥、证书、抓包原文
- [ ] 微应用桥未过度暴露宿主能力
